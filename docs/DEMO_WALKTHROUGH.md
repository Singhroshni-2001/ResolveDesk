# A three-minute ResolveDesk walkthrough

1. Start at the home screen. Click **Try the interactive demo**. Point out the demo label and fictional Nova Store.
2. Open **Support chat** and choose “What is your return policy?” The response says **Saved answer**, not live AI. Expand **Returns & refunds · Page 1** to show the exact excerpt.
3. Ask “Where is my order?” The demo honestly says it does not have a verified answer. Choose **Create ticket**.
4. Fill a subject, category and description. Show that the ticket is created only after **Confirm & create ticket**.
5. As an agent, add a reply and change status to **In progress**, then **Resolved**. Open Analytics to show counts changing and resolution time computed from timestamps.
6. Switch to **Customer view**. Alex sees Alex's tickets and replies; agent-only navigation and status controls disappear. This is a simulated perspective switch, not live authorization.
7. Switch back to Agent. Explore the three source policies in Knowledge. Explain that actual uploads require authenticated live mode.
8. Refresh: demo ticket changes persist locally. **Reset demo** restores the fictional sample after confirmation.
9. Select **Go live**. Without environment settings, the app explains that live mode is not configured and links back to the demo.

When live setup is complete, use two separate browser sessions for a customer and an owner-provisioned agent. Demonstrate a real TXT upload, ready status, a cited Gemini answer, a confirmed ticket, an agent reply and customer isolation. Never present the saved demo answers as a live integration test.
